# 云端训练指南：区域分割模型（30 分钟，约 1 元）

> 为什么上云：本地拿不到预训练权重 `yolo11n-seg.pt`（GitHub 超时、镜像失效），
> 从零训练 26 张图只能到 mAP 0.065。云服务器自带预训练权重，微调 100 轮能到 0.3~0.5。

---

## 第 1 步：上传数据集（本地，3 分钟）

要上传的文件：

```
桌面\校园违停检测_版本迭代\v8_合并版\_本次更新_2026-11-17\zones_ds_26张.zip
```

1. 登录矩池云 <https://matpool.com>
2. 进入「**网盘**」（不是实例）
3. 上传 `zones_ds_26张.zip` 到网盘根目录

> 网盘（`/mnt`）关机后数据还在；实例本地（`/root`）关机就清空。

---

## 第 2 步：开机器（2 分钟）

| 选项 | 选什么 |
|---|---|
| 区域 | **1 区** |
| 显卡 | **A2000**（0.9 元/小时，够用） |
| 镜像 | **PyTorch 2.0.1 + Python 3.8** |
| 开机后 | 进入 JupyterLab |

---

## 第 3 步：解压数据（1 分钟）

在 JupyterLab 新建 **Terminal**，粘这三行：

```bash
cd /root
cp /mnt/zones_ds_26张.zip .
unzip -q "zones_ds_26张.zip"
ls zones_ds
```

**应该看到**：`data.yaml  images  labels`

检查 `data.yaml` 里的路径：

```bash
cat zones_ds/data.yaml
```

里面的 `path:` 是本地路径，**要改成云端的**：

```bash
sed -i "s|^path:.*|path: /root/zones_ds|" zones_ds/data.yaml
cat zones_ds/data.yaml
```

**应该看到** `path: /root/zones_ds`。

---

## 第 4 步：开始训练（10 分钟）

```bash
cd /root
yolo segment train \
  data=/root/zones_ds/data.yaml \
  model=yolo11n-seg.pt \
  imgsz=640 \
  epochs=100 \
  batch=8 \
  amp=False \
  project=/mnt/runs \
  name=zones_gpu
```

### 参数说明

| 参数 | 作用 |
|---|---|
| `model=yolo11n-seg.pt` | **预训练权重**，云端自带，自动下载 |
| `amp=False` | **必须加**，否则会卡在 AMP 检查（下权重超时） |
| `project=/mnt/runs` | 输出到网盘，关机不丢 |
| `epochs=100` | 26 张图，100 轮足够 |

### 训练中会看到

```
Epoch   GPU_mem   box_loss   seg_loss  ...  Mask mAP50
  1/100     0.8G     3.21       4.05         0.012
 ...
 50/100     0.8G     1.42       2.11         0.31
100/100     0.8G     1.18       1.87         0.42
```

**目标：Mask mAP50 ≥ 0.3**。低于 0.2 就说明数据还是太少。

---

## 第 5 步：下载权重（2 分钟）

训练完成后：

```bash
ls /mnt/runs/zones_gpu/weights/
```

**应该是**：`best.pt  last.pt`

在 JupyterLab 左侧文件树里找到 `/mnt/runs/zones_gpu/weights/best.pt`，
右键 → **Download** 下载到电脑。

---

## 第 6 步：本地部署（1 分钟）

1. 把下载的 `best.pt` 改名成 **`zones.pt`**
2. 放到 **`D:\models\zones.pt`**
3. 重启网页：

```cmd
双击 桌面\校园违停检测_版本迭代\v8_合并版\桌面版.bat
```

**启动日志应该出现**：

```
[区域模型] D:\models\zones.pt  ← 「自动识别区域」按钮可用
```

4. 网页里拖一张图 → 点「**自动识别区域**」→ 自动画出禁停区

## 第 7 步：关机（省钱）

JupyterLab 右上角 → 关机。

**别忘了**：`/root` 里的东西会清空，但 `/mnt`（网盘）里的数据和权重还在。

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `yolo: command not found` | 用了非交互 shell | 直接 `python -c "from ultralytics import YOLO"` 测试，或换 Terminal 而不是 tmux |
| 卡在 `AMP checks...` | 没加 `amp=False` | 加参数重跑 |
| `No labels found` | data.yaml 路径不对 | 检查 `path:` 是否指向 `/root/zones_ds` |
| 训练完 mAP 还是 0.1 | 数据太少 | 每类场景补到 100 张 |
| 下载 best.pt 很慢 | 文件 6 MB，正常 1~2 分钟 | 耐心等 |
