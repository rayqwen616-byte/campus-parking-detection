# 桌面应用使用说明

## 一、三种启动方式

| 方式 | 双击哪个 | 说明 |
|---|---|---|
| **① 桌面快捷方式**（推荐） | 桌面上的 **「校园违停检测」** 图标 | 双击即开原生窗口 |
| **② exe 直接运行** | 本目录 **`校园违停检测.exe`** | 与快捷方式等价 |
| ③ 脚本方式 | `校园违停检测.pyw` | 开发调试用，逻辑相同 |

启动后：会先起后台服务（约 10～20 秒，加载两个模型），然后弹出应用窗口。

**关闭窗口 = 自动结束后台服务**，不会留残余进程。

---

## 二、它是怎么实现的

```
校园违停检测.exe
   │
   ├─ ① 后台启动 webapp.py（独立进程，不弹黑窗）
   ├─ ② 轮询 /api/health 直到就绪
   ├─ ③ 用 pywebview(WebView2) 打开原生窗口
   └─ ④ 窗口关闭 → 结束服务进程
```

- 用的是 **系统自带 WebView2**（Win11 预装），不需要装浏览器
- 窗口无地址栏、无标签页，和普通桌面软件一样
- 服务端口自动选择（默认 8000，被占用就往后找）

## 三、依赖说明

| 依赖 | 是否必须 | 说明 |
|---|---|---|
| `D:\yolo_env\Scripts\python.exe` | **必须** | 后端服务由它运行，exe 只是启动器 |
| `D:\models\ebike26.pt` | **必须** | 检测模型 |
| `D:\models\zones.pt` | 可选 | 区域模型，没有则「自动识别区域」不可用 |
| WebView2 运行时 | Win11 自带 | Win10 需装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) |

> exe 只有 14 MB，因为它**不打包含 PyTorch**（打进去会变成 1.5 GB+）。
> 所以它依赖本机已有的 `D:\yolo_env` 环境。

---

## 四、启动太慢怎么办

首次启动要加载两个模型（约 10～20 秒）。如果嫌慢：

1. 删掉 `D:\models\zones.pt` → 只加载检测模型，快一半（但自动识别区域不可用）
2. 或保持现状，启动后等服务就绪窗口才出现（不会卡死）

---

## 五、出问题怎么查

| 现象 | 原因 | 解决 |
|---|---|---|
| 双击后没反应 | 服务启动失败 | 在该目录打开 cmd，运行 `D:\yolo_env\Scripts\python.exe desktop.py` 看报错 |
| 窗口白屏 | WebView2 未安装或端口被占 | 确认能浏览器打开 `http://127.0.0.1:8000` |
| 提示「模型未加载」 | 权重路径不对 | 检查 `D:\models\ebike26.pt` 是否存在 |
| 关窗口后进程残留 | 服务进程未退出 | 任务管理器结束 `python.exe` |

排错日志：`_desktop_error.log`（双击 pyw 出错时生成）

---

## 六、重新打包 exe

如果改了代码要重新打包：

```cmd
cd /d 本目录
D:\yolo_env\Scripts\python.exe -m PyInstaller --noconfirm --onefile --noconsole ^
  --name campus_parking --icon D:\app_icon.ico ^
  --distpath . --workpath _build --specpath _build desktop.py
```

打包完成后把 `campus_parking.exe` 改名 `校园违停检测.exe`。

> 注意：图标路径必须是**纯英文路径**，否则 PyInstaller 会报 `Icon input file not found`。
