## 两个值得记录的 bug（v11 修复）

### 1. 标注图不显示

前端拼 `data:image/jpeg;base64,` 前缀，后端又返回了一次 → 双层前缀 → 浏览器无法解析。
**修法**：后端只返回纯 base64。

### 2. 掩码坐标整体错位

ultralytics 返回的 `masks.data` 分辨率不是原图（1279×1706 的图返回 480×640），
原代码按原图尺寸归一化 → 坐标压到左上角。

| | 平均 IoU | 命中 |
|---|---|---|
| 修复前 | 0.0095 | 0 / 30 |
| 修复后 | 0.6605 | 34 / 40 |

**同一个模型，只改归一化方式，指标差 70 倍。**
