# 数据标注规范

## 一、三个类别

| 类别 | 含义 | 例子 |
|---|---|---|
| `forbidden` | 禁停区 | 楼道口、消防通道、人行道、绿化带边 |
| `passage` | 正常通行区 | 走廊、通道、走道 |
| `legal` | 合法停车区 | 白线车位框内 |

> `legal` 是 v11 新增的对比类：只教"哪里禁停"，模型靠排除法；
> 同时教"哪里可以停"，边界判定明显更准。

## 二、绘制规则

1. 用 labelme 画**多边形**，沿地面交界线走，不要把墙、台阶画进去
2. 材质变化即为边界（砖路 / 水泥 / 盲道 / 草地）
3. **判断标准：一辆电动车能不能完整停在这块地上？**
   - 能 → 不是禁停区
   - 不能 / 不该 → 禁停区
4. 宽度小于 1 米的区域不要标
5. 每个多边形至少 3 个点

## 三、图像采集

| 项 | 要求 |
|---|---|
| 时间 | 白天（自然光），避免夜景 |
| 高度 | 1.5 ～ 2 m |
| 俯角 | 15° ～ 30° |
| 每点位 | 正面 / 左 45° / 右 45°，近远各一张 |
| 传输 | 必须勾选"原图"，单张 2 MB 以上 |

## 四、质量校验

- 两人独立标注同一张图，IoU ≥ 0.7 视为一致
- 转换后检查 `跳过空标注 0 张`
- 类别名必须是小写精确匹配（`forbidden` 不是 `Forbidden`）
