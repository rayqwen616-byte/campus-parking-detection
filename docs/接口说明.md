# 接口说明（HTTP API）

> 后端为单文件 `src/webapp.py`，使用 Python 标准库 `http.server`，**无 Web 框架依赖**。
> 默认监听 `127.0.0.1:8000`。

---

## 通用约定

| 项 | 说明 |
|---|---|
| 编码 | UTF-8 |
| 请求体 | JSON（`Content-Type: application/json`） |
| 响应体 | JSON |
| 图片传输 | Base64 Data URL，形如 `data:image/jpeg;base64,/9j/4AAQ...` |
| 图片大小上限 | 解码后 18 MB |
| 请求体上限 | 36 MB（Base64 膨胀系数） |
| 支持格式 | JPEG / PNG / WEBP / BMP |
| 成功标志 | `"ok": true` |
| 失败标志 | `"ok": false` + `"error": "原因"`，HTTP 400 |

---

## 1. `GET /api/health`

健康检查与模型状态。

### 响应

```json
{
  "ok": true,
  "model_loaded": true,
  "model": "ebike26.pt",
  "keep": ["bicycle", "ebike"],
  "zone_model_available": true,
  "zone_model": "zones.pt"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `model_loaded` | bool | 检测模型是否已加载 |
| `model` | string | 检测模型文件名 |
| `keep` | string[] | 参与统计的类别（白名单） |
| `zone_model_available` | bool | 区域分割模型是否可用 |
| `zone_model` | string\|null | 区域模型文件名 |

---

## 2. `POST /api/detect`

对一张图片做检测 + 区域判定。

### 请求

```json
{
  "image": "data:image/jpeg;base64,/9j/4AAQ...",
  "confidence": 0.25,
  "zones": [
    {
      "name": "消防通道",
      "level": 1,
      "points": [[0.0, 0.45], [0.45, 0.38], [0.50, 1.0], [0.0, 1.0]]
    }
  ]
}
```

| 字段 | 必填 | 类型 | 约束 |
|---|---|---|---|
| `image` | ✅ | string | Data URL，解码后 ≤ 18 MB |
| `confidence` | ❌ | float | 0 < x < 1，默认 0.25 |
| `zones` | ❌ | array | 最多 10 个区域 |
| `zones[].name` | ❌ | string | ≤ 40 字符，默认"禁停区" |
| `zones[].level` | ❌ | int | 1 / 2 / 3，默认 1 |
| `zones[].points` | ✅ | array | 3 ～ 32 个 `[x, y]`，取值 0 ～ 1 |
| `zones[].color` | ❌ | int[3] | BGR，每个 0 ～ 255 |

### 响应

```json
{
  "ok": true,
  "width": 1279,
  "height": 1706,
  "model": "ebike26.pt",
  "summary": { "total": 2, "inside": 1, "outside": 1 },
  "detections": [
    {
      "label": "自行车",
      "model_label": "bicycle",
      "confidence": 0.8305,
      "box": [339, 606, 828, 977],
      "foot": [583.5, 977.0],
      "status": "inside",
      "zone": "消防通道",
      "level": 1
    }
  ],
  "annotated_image": "/9j/4AAQSkZJRgABAQ...",
  "elapsed_ms": 1686.8
}
```

| 字段 | 说明 |
|---|---|
| `summary.total` | 检出的非机动车总数 |
| `summary.inside` | 脚点落在禁停区内的数量 |
| `summary.outside` | 脚点在区域外的数量 |
| `detections[].label` | 中文显示名 |
| `detections[].model_label` | 模型原始类别名 |
| `detections[].foot` | 脚点坐标（框底边中点），判定依据 |
| `detections[].status` | `inside` / `outside` |
| `detections[].zone` | 命中区域名（未命中为 `null`） |
| `detections[].level` | 命中区域等级（未命中为 `null`） |
| `annotated_image` | **纯 Base64**（不含 `data:` 前缀，由前端拼接） |
| `elapsed_ms` | 本次推理耗时（毫秒） |

> ⚠️ `inside` 只表示"车辆位于禁停区内"，**不代表已满足停留时长**。
> 违停判定需走视频流程（`demo_v8.py`）。

## 3. `POST /api/zones`

自动识别图片中的禁停区，返回可直接用于 `/api/detect` 的区域列表。
需要区域分割模型（`models/zones.pt`）。

### 请求

```json
{ "image": "data:image/png;base64,iVBOR...", "confidence": 0.25 }
```

### 响应

```json
{
  "ok": true,
  "count": 1,
  "zones": [
    {
      "name": "禁停区1",
      "level": 1,
      "points": [[0.1234, 0.4567], [0.8321, 0.4412], [0.9001, 0.9812]]
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `count` | 识别出的区域数 |
| `zones[].points` | 归一化多边形，可直接回传 `/api/detect` |

> 只输出 `forbidden` 类别；`passage`、`legal` 不会生成禁停区。
> 自动结果**必须人工核对**后再用于判定。

### 未加载区域模型时

```json
{ "ok": false, "error": "未加载区域分割模型（需要 models/zones.pt）" }
```

## 4. 错误码

| HTTP | `error` 示例 | 触发条件 |
|---|---|---|
| 400 | `图片格式不正确` | `image` 不是 Data URL |
| 400 | `只支持 JPEG、PNG 或 WEBP 图片` | 解码后格式不支持 |
| 400 | `图片太大` | 超过 18 MB |
| 400 | `置信度必须在 0 到 1 之间` | `confidence` 越界 |
| 400 | `区域必须是列表且不超过 10 个` | `zones` 结构错 |
| 400 | `每个区域需要 3 至 32 个顶点` | `points` 数量错 |
| 400 | `顶点坐标必须是 0 到 1 的数字` | 坐标越界 |
| 400 | `区域等级必须是 1、2 或 3` | `level` 非法 |
| 404 | `未知接口` | 路径不存在 |

## 5. 调用示例

### Python

```python
import base64, json, urllib.request
from pathlib import Path

img = Path("photo.jpg").read_bytes()
payload = {
    "image": "data:image/jpeg;base64," + base64.b64encode(img).decode(),
    "confidence": 0.25,
    "zones": [{"name": "测试区", "level": 1,
               "points": [[0, 0.5], [0.6, 0.45], [0.65, 1], [0, 1]]}],
}
req = urllib.request.Request(
    "http://127.0.0.1:8000/api/detect",
    data=json.dumps(payload).encode(),
    headers={"Content-Type": "application/json"},
)
result = json.loads(urllib.request.urlopen(req, timeout=120).read())
print(result["summary"])
```

### curl

```bash
curl -s http://127.0.0.1:8000/api/health
```

## 6. 并发说明

- 服务为多线程（`ThreadingHTTPServer`）
- 模型推理**串行执行**（内部有推理锁），避免同一模型实例被并发调用
- 因此并发请求会排队，响应时间随并发数线性增长

---

## 7. 前端契约

前端 `src/index.html` 与后端约定：

```js
// 前端自行拼接前缀
state.resultUrl = `data:image/jpeg;base64,${data.annotated_image}`;
```

**后端返回纯 Base64，不要再带 `data:` 前缀**，否则前端会出现双层前缀导致图片无法显示
（v11 修复的 bug）。
