# 部署说明

## 一、网页端

```bash
python src/webapp.py --model models/ebike26.pt --zone-model models/zones.pt
```

- 默认监听 `127.0.0.1:8000`
- 接口：`GET /api/health`、`POST /api/detect`、`POST /api/zones`
- 模型查找顺序：`models/` → `D:/models/` → 训练目录最新

## 二、桌面端（Windows）

`src/desktop.py` 用 pywebview 打开原生窗口（WebView2），
关闭窗口自动结束后台服务。

```bash
python src/desktop.py            # 有控制台
pythonw src/desktop.py           # 无控制台
```

打包 exe：

```bash
pyinstaller --noconfirm --onefile --noconsole --name campus_parking src/desktop.py
```

> 打包时不要包含 PyTorch（会变成 1.5 GB+）。exe 作为启动器，
> 后端仍由本机 Python 环境运行。

## 三、视频判定

```bash
python src/demo_v8.py ^
  --source video.mp4 ^
  --model models/ebike26.pt ^
  --zones src/zones.json ^
  --speed 10
```

| 参数 | 说明 |
|---|---|
| `--speed` | 时间加速倍数（演示用 10） |
| `--stride` | 隔帧处理，降低算力 |
| `--no-video` | 不输出视频，只出事件 |

## 四、区域配置

`src/zones.json` 结构：

```json
{
  "zones": [
    {"name": "消防通道", "level": 1, "dwell": 10, "cooldown": 300,
     "color": [0, 0, 255],
     "points": [[0.0, 0.45], [0.45, 0.38], [0.50, 1.0], [0.0, 1.0]]}
  ]
}
```

- `level`：1 最严重，重叠时取最小
- `dwell`：停留多少秒判违停
- `cooldown`：同位置多少秒内不重复报警
- `color`：BGR 顺序
- `points`：0～1 归一化坐标

生成方式：网页手画导出、`pick_roi.py` 点选、或 `predict_zones.py` 自动识别。

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: cv2` | 用了系统 Python | 用项目虚拟环境 |
| 标注图不显示 | 前后端 base64 前缀重复 | v11 已修 |
| 区域框错位 | 掩码归一化尺寸错误 | v11 已修 |
| `yolo: command not found` | 非交互 shell 没有 PATH | 用 `python -c "from ultralytics import YOLO; ..."` |
